Data profile

Every column is inspected before anything is fixed: type inference, missing values, distinct values, duplicates. The numbers here are the baseline the cleaning report is measured against. You can override the inferred type of any column the pipeline re-runs with your choice.

Column profile

ColumnInferred typeMissingDistinctSample values

Types drive the rules: date columns get format unification, numeric columns get coercion / outlier / imputation logic, category columns get casing + typo merging, identifier columns are left verbatim, text columns are trimmed only.

Cleaning rules

Twelve ordered rules run top to bottom. Toggle any rule and the dataset re-cleans instantly the report, tables and charts all update. Badges show how many rows each rule touched on the last run.

Cleaning report

Every rule logs what it did and how many rows or cells it touched. The result strip compares the raw table against the final one; the column table shows the before → after movement per column.

    Browse rows

    Switch between the raw table and the cleaned one. In the cleaned view every modified cell is highlighted hover it to see the original value. Rows removed by the pipeline stay visible (greyed, struck through) with the rule that dropped them. Search filters both views.

    Export results
